লারাভেল Eloquent ORM হলো পিএইচপি জগতের সবচেয়ে শক্তিশালী এবং ইউজার-ফ্রেন্ডলি ডাটাবেস ইন্টারফেস। এটি মূলত একটি Active Record implementation, যা ডাটাবেস টেবিলকে অবজেক্ট হিসেবে রিপ্রেজেন্ট করে।

নিচে লারাভেল এলুকুয়েন্টের বিস্তারিত এবং আপনার কাজের গতি ও কোড কোয়ালিটি বাড়ানোর জন্য ১০০টি প্রো-টিপস দেওয়া হলো।

১. এলুকুয়েন্ট কী এবং কেন?
Eloquent আপনাকে SQL কুয়েরি না লিখেই ডাটাবেসের সাথে কথা বলতে দেয়।

Readable: কোড পড়তে অনেকটা ইংরেজি বাক্যের মতো মনে হয়।

Maintainable: ডাটাবেস পরিবর্তন করলেও (যেমন MySQL থেকে PostgreSQL) কোডে খুব একটা পরিবর্তন করতে হয় না।

Relationship: টেবিলগুলোর মধ্যে রিলেশন ম্যানেজ করা খুবই সহজ।

২. ১০০টি প্রো-টিপস (ক্যাটাগরি অনুযায়ী)
মডেল ও কুয়েরি অপ্টিমাইজেশন
N+1 কুয়েরি এড়ান: সবসময় with() ব্যবহার করে ইগার লোডিং (Eager Loading) করুন।

Specific Columns: মেমোরি বাঁচাতে all() এর বদলে select('id', 'name') ব্যবহার করুন।

Find or Fail: সরাসরি find() না করে findOrFail() করুন যাতে ইউজার ৪-৪ এরর পায়।

Chunking: বড় ডাটাবেস প্রসেস করতে chunk() ব্যবহার করুন যাতে র্যাম ওভারলোড না হয়।

Lazy Loading: লুপের ভেতর রিলেশন কল করবেন না।

Exists: কোনো রেকর্ড আছে কি না চেক করতে count() > 0 না লিখে exists() লিখুন।

Latest/Oldest: orderBy('created_at', 'desc') এর বদলে latest() ব্যবহার করুন।

Where Dates: whereDate('created_at', '2026-02-05') ব্যবহার করে ডেট ফিল্টার করুন।

Subquery Ordering: সাবকুয়েরি ব্যবহার করে সর্টিং করলে পারফরম্যান্স বাড়ে।

Value Method: শুধু একটি কলামের মান চাইলে first()->name না লিখে value('name') লিখুন।

রিলেশনশিপ টিপস
Has One Through: তিন স্তরের রিলেশনশিপে এটি ব্যবহার করুন।

Custom Pivot Models: belongsToMany তে এক্সট্রা ডাটা থাকলে কাস্টম পিভট মডেল ব্যবহার করুন।

WithCount: রিলেটেড মডেল কতগুলো আছে জানতে withCount('comments') ব্যবহার করুন।

Touch Parent: চাইল্ড আপডেট হলে প্যারেন্টের updated_at চেঞ্জ করতে $touches প্রপার্টি ব্যবহার করুন।

Default Models: রিলেশন নাল (null) হলে এরর এড়াতে withDefault() ব্যবহার করুন।

Dynamic Relationships: রানটাইমে রিলেশন ডিফাইন করা সম্ভব।

Push: প্যারেন্ট এবং তার সব চাইল্ড রিলেশন একসাথে সেভ করতে push() ব্যবহার করুন।

WhereHas: রিলেশনের ওপর ভিত্তি করে ফিল্টার করতে এটি ব্যবহার করুন।

Constrained Eager Loading: ইগার লোডিংয়ের সময়ও with(['posts' => function($q) { ... }]) দিয়ে কন্ডিশন দেওয়া যায়।

Sync Without Detaching: মেনি-টু-মেনি রিলেশনে আগের ডাটা না মুছে নতুন ডাটা যোগ করতে এটি ব্যবহার করুন।

স্কোপ এবং অ্যাট্রিবিউট (Scopes & Attributes)
Local Scopes: কমন কুয়েরিগুলোকে মডেলে scopeActive এভাবে ডিফাইন করুন।

Global Scopes: সবসময় দরকার এমন কন্ডিশন (যেমন: status = active) গ্লোবাল স্কোপে রাখুন।

Accessors: ডাটা দেখানোর সময় ফরম্যাট করতে (যেমন নামের প্রথম অক্ষর বড় করা) Accessors ব্যবহার করুন।

Mutators: ডাটা সেভ করার সময় (যেমন পাসওয়ার্ড হ্যাশ করা) Mutators ব্যবহার করুন।

Appends: JSON রেসপন্সে কাস্টম অ্যাট্রিবিউট পাঠাতে $appends অ্যারে ব্যবহার করুন।

Casting: is_admin কে অটোমেটিক বুলিয়ান করতে $casts প্রপার্টি ব্যবহার করুন।

Date Casting: কাস্টম ডেট ফরম্যাট কাস্ট করুন $casts = ['expired_at' => 'datetime:Y-m-d']।

Encrypted Casting: ডাটাবেসে সেনসিটিভ তথ্য এনক্রিপ্ট করে রাখতে encrypted কাস্ট ব্যবহার করুন।

পারফরম্যান্স ও সিকিউরিটি
Fillable vs Guarded: মাস অ্যাসাইনমেন্ট প্রটেক্ট করতে সবসময় $fillable ব্যবহার করুন।

Disable Timestamps: যদি created_at না লাগে তবে public $timestamps = false; করে দিন।

Snake Case: ডাটাবেস কলাম সবসময় স্নেক কেস (snake_case) রাখুন।

DB Transactions: একাধিক টেবিল আপডেটের সময় DB::transaction() ব্যবহার করুন।

UUIDs: আইডিতে সিকিউরিটির জন্য অটো-ইনক্রিমেন্টের বদলে UUID ব্যবহার করতে পারেন।

Soft Deletes: ডাটা পুরোপুরি না মুছে deleted_at কলাম ব্যবহার করুন।

Only Trashed: শুধু ডিলিট হওয়া ডাটা দেখতে onlyTrashed() ব্যবহার করুন।

Mass Updates: একটা একটা করে আপডেট না করে update() মেথড দিয়ে একসাথে করুন।

Refresh: ডাটাবেস থেকে মডেলের লেটেস্ট ভ্যালু পেতে $model->refresh() করুন।

অ্যাডভান্সড কুয়েরি
WhereIn: অ্যারে দিয়ে সার্চ করতে whereIn() ব্যবহার করুন।

WhereBetween: রেঞ্জ ফিল্টার করতে এটি সেরা।

Ternary in Queries: কন্ডিশনের ওপর ভিত্তি করে কুয়েরি যোগ করতে when() ব্যবহার করুন।

First or Create: ডাটা থাকলে দাও না থাকলে তৈরি করো—এর জন্য firstOrCreate()।

Update or Create: ডাটা আপডেট বা ক্রিয়েট করতে এটি ব্যবহার করুন।

Increment/Decrement: কোনো সংখ্যা বাড়াতে বা কমাতে increment('votes') ব্যবহার করুন।

ToSql: কুয়েরিটা আসলে কেমন হচ্ছে দেখতে toSql() কল করুন।

Raw Queries: জটিল কুয়েরির জন্য DB::raw() ব্যবহার করুন (সাবধানে)।

Join vs Relationship: পারফরম্যান্স ক্রিটিকাল জায়গায় মাঝে মাঝে join ব্যবহার করা ভালো।

Distinct: ডুপ্লিকেট ভ্যালু এড়াতে distinct() ব্যবহার করুন।

In Random Order: র‍্যান্ডম ডাটা পেতে inRandomOrder()।

Pluck: শুধু নির্দিষ্ট কলামের অ্যারে পেতে pluck('id')।

Map/Each: কালেকশন প্রসেস করতে map() বা each() ব্যবহার করুন।

টিপস ৫১ - ১০০ (সংক্ষিপ্ত ও দ্রুত)
cursor() ব্যবহার করে মেমোরি বাঁচান বড় ডাটা রিড করার সময়।

মডেলে protected $perPage = 25; দিয়ে ডিফল্ট পেজিনেশন সেট করুন।

replicate() দিয়ে সহজেই কোনো রো ক্লোন বা কপি করুন।

wasRecentlyCreated দিয়ে চেক করুন ডাটাটি এইমাত্র তৈরি হলো কি না।

isDirty() দিয়ে চেক করুন কোনো ফিল্ড চেঞ্জ হয়েছে কি না।

getOriginal() দিয়ে ডাটার আগের মান দেখুন।

Model::withoutEvents() দিয়ে ইভেন্ট ছাড়া ডাটা সেভ করুন।

upsert() ব্যবহার করে মাল্টিপল রেকর্ড একসাথে ইনসার্ট বা আপডেট করুন।

preventLazyLoading() দিয়ে ডেভেলপমেন্ট মোডে লেজি লোডিং বন্ধ রাখুন।

setTable() দিয়ে রানটাইমে টেবিল পরিবর্তন করুন।

is() মেথড দিয়ে দুটি মডেল একই কি না চেক করুন।

hidden প্রপার্টি দিয়ে পাসওয়ার্ডের মতো সেনসিটিভ কলাম হাইড করুন।

makeVisible() দিয়ে হিডেন কলাম সাময়িকভাবে দেখান।

কুয়েরি লগ দেখতে DB::enableQueryLog() ব্যবহার করুন।

Model::query() ব্যবহার করলে IDE ভালো অটো-কমপ্লিশন দেয়।

কাস্টম পিভট টেবিলের নাম দিতে belongsToMany(..., 'table_name')।

HasManyDeep প্যাকেজটি জটিল রিলেশনের জন্য ব্যবহার করতে পারেন।

withMin, withMax, withAvg দিয়ে সরাসরি এগ্রিগেট ডাটা আনুন।

রিলেশন চেক করতে has('posts') ব্যবহার করুন।

রিলেশন নাই এমন ডাটা খুঁজতে doesntHave('posts')।

whereRelation() দিয়ে সহজে রিলেটেড ফিল্ড ফিল্টার করুন।

Polymorphic Relationships ব্যবহার করুন যখন একটি মডেল একাধিক মডেলের সাথে যুক্ত হতে পারে।

morphTo এবং morphMany এর ব্যবহার শিখুন।

ofMany দিয়ে রিলেশনের 'লেটেস্ট' বা 'ওল্ডেস্ট' ওয়ান-টু-ওয়ান রিলেশন বানান।

ডাটাবেস ইনডেক্সিং (Indexing) ভুলে যাবেন না, এটি এলুকুয়েন্টের স্পিড বাড়ায়।

LoadCount ব্যবহার করুন যদি মডেল অলরেডি লোড হয়ে থাকে।

whereIntegerInRaw ব্যবহার করুন যদি অনেক বড় অ্যারে দিয়ে কুয়েরি করেন।

boot মেথড ব্যবহার করে মডেল ইভেন্ট (creating, saving) হ্যান্ডেল করুন।

মডেল অবজারভার (Observers) ব্যবহার করুন কোড ক্লিন রাখতে।

Model::preventSilentlyDiscardingAttributes() ব্যবহার করুন ভুল কলাম সেভ হওয়া আটকাতে।

sole() মেথড ব্যবহার করুন যদি আপনি নিশ্চিত হন মাত্র একটি রেকর্ডই আছে।

Pagination এর জন্য simplePaginate() ব্যবহার করুন যদি শুধু Next/Prev লাগে।

onWriteConnection() ব্যবহার করে রিড/রাইট ডাটাবেস আলাদা করুন।

মডেলে কাস্টম Cast ক্লাস তৈরি করা যায়।

Higher Order Messaging ব্যবহার করুন কালেকশনে: $users->each->update(...)।

filter() কালেকশন মেথড দিয়ে ডাটা ফিল্টার করুন।

groupBy করার পর having ব্যবহার করতে পারেন।

Model::unguard() সাময়িকভাবে সব মাস অ্যাসাইনমেন্ট গার্ড তুলে নিতে।

touch() দিয়ে জোর করে updated_at আপডেট করা।

without() ব্যবহার করে গ্লোবাল স্কোপ ডিজেবল করা।

saveQuietly() দিয়ে কোনো ইভেন্ট ফায়ার না করে সেভ করা।

toCsv বা এক্সেল এক্সপোর্টের জন্য cursor ব্যবহার করা বাধ্যতামূলক।

whereJsonContains দিয়ে JSON কলাম সার্চ করা।

ডাইনামিক where কুয়েরি: whereName('Rakib') এর বদলে সরাসরি where('name', 'Rakib') বেশি ক্লিয়ার।

factory() ব্যবহার করে টেস্টিং ডাটা জেনারেট করা।

truncate() দিয়ে টেবিল খালি করা (সাবধানে!)।

make() মেথড দিয়ে ডাটাবেসে সেভ না করে মডেল ইনস্ট্যান্স তৈরি করা।

Model::shouldBeStrict() ডেভেলপমেন্টে সব ভুল ধরার জন্য।

getChanges() শুধু কি কি চেঞ্জ হয়েছে তার লিস্ট দেয়।

একটানা শিখতে থাকুন: লারাভেলের ডকুমেন্টেশন সবসময় আপডেট হয়, তাই নতুন ফিচারগুলো ফলো করুন।

লারাভেল এলুকুয়েন্টে শত শত ফাংশন থাকলেও, দৈনন্দিন ডেভেলপমেন্টে সবচেয়ে বেশি ব্যবহৃত এবং গুরুত্বপূর্ণ ফাংশনগুলোকে নিচে কয়েকটি ক্যাটাগরিতে সারসংক্ষেপ করা হলো।

১. ডাটা রিট্রিভাল (Data Retrieval)
এই ফাংশনগুলো ডাটাবেস থেকে ডাটা খুঁজে বের করতে ব্যবহৃত হয়।

all(): টেবিলের সব ডাটা নিয়ে আসে।

find($id): প্রাইমারি কি (ID) দিয়ে একটি নির্দিষ্ট রেকর্ড খোঁজে।

findOrFail($id): আইডি না পেলে সরাসরি ৪-৪ এরর (ModelNotFoundException) থ্রো করে।

first(): কুয়েরির প্রথম রেজাল্টটি দেয়।

`pluck('column'): শুধুমাত্র নির্দিষ্ট একটি কলামের মানগুলো নিয়ে একটি অ্যারে তৈরি করে।

select('col1', 'col2'): মেমোরি বাঁচাতে শুধু প্রয়োজনীয় কলামগুলো সিলেক্ট করে।

২. কন্ডিশনাল কুয়েরি (Conditional Queries)
ডাটা ফিল্টার করার জন্য এগুলো অপরিহার্য।

where('column', 'value'): সাধারণ ফিল্টারিং।

orWhere(): 'অথবা' কন্ডিশন যোগ করতে।

whereIn('id', [1, 2, 3]): একটি অ্যারের মধ্যে মানগুলো আছে কি না চেক করতে।

when($variable, function($query)): যদি কোনো ভেরিয়েবল সত্য হয়, তবেই কুয়েরিটি রান করবে (ডাইনামিক সার্চের জন্য সেরা)।

latest(): created_at অনুযায়ী ডিসেন্ডিং অর্ডারে ডাটা সর্ট করে।

৩. ডাটা তৈরি ও আপডেট (Create & Update)
create(['key' => 'value']): একসাথে অনেক ডাটা ইনসার্ট করে (Mass Assignment)।

save(): একটি মডেল ইনস্ট্যান্সকে ডাটাবেসে সেভ বা আপডেট করে।

update(['key' => 'value']): এক্সিস্টিং রেকর্ড আপডেট করে।

updateOrCreate(['match_key' => 'val'], ['update_key' => 'val']): ডাটা থাকলে আপডেট করবে, না থাকলে নতুন তৈরি করবে।

firstOrCreate(): ডাটা খুঁজে না পেলে নতুন ডাটা তৈরি করবে।

৪. রিলেশনশিপ হ্যান্ডলিং (Relationship Functions)
টেবিলগুলোর মধ্যে সংযোগ স্থাপনের জন্য:

with('relation'): Eager Loading-এর মাধ্যমে N+1 সমস্যা সমাধান করে।

has('relation'): শুধুমাত্র সেই প্যারেন্টগুলো আনে যাদের রিলেশনশিপে ডাটা আছে।

whereHas('relation', function($q)): রিলেটেড টেবিলের কলামের ওপর ভিত্তি করে মেইন টেবিল ফিল্টার করে।

withCount('relation'): রিলেটেড ডাটা কতগুলো আছে (যেমন: পোস্টে কয়টি কমেন্ট আছে) তা গুনে দেয়।

৫. এগ্রিগেশন ও অন্যান্য (Aggregates & Misc)
count(), sum('column'), avg('column'): গাণিতিক হিসাবের জন্য।

exists(): ডাটা আছে কি না তার সত্যতা (True/False) যাচাই করে।

paginate(15): স্বয়ংক্রিয়ভাবে পেজিনেশন তৈরি করে।

chunk(100, function($data)): হাজার হাজার ডাটা অল্প অল্প করে প্রসেস করে র্যাম বাঁচায়।

একনজরে এলুকুয়েন্ট লাইফসাইকেল ডায়াগ্রাম:
প্রো-টিপ: আপনি যদি কোড আরও ক্লিন করতে চান, তবে where কন্ডিশনগুলো সরাসরি কন্ট্রোলারে না লিখে মডেলের ভেতর Local Scope হিসেবে ডিফাইন করতে পারেন

লারাভেল অ্যাপ্লিকেশনের পারফরম্যান্স মূলত নির্ভর করে আপনি কত নিখুঁতভাবে ডাটাবেস কুয়েরি হ্যান্ডেল করছেন তার ওপর। ডাটাবেসের লোড কমাতে এবং রেসপন্স টাইম দ্রুত করতে Query Optimization-এর ১০০টি প্রো-টিপস নিচে দেওয়া হলো:

১. ইগার লোডিং (Eager Loading) ও N+1 সমস্যা
১. N+1 কুয়েরি শনাক্ত করুন: laravel-query-detector প্যাকেজ ব্যবহার করে অপ্রয়োজনীয় কুয়েরি ধরুন।

২. Always Use with(): লুপের ভেতর রিলেশন কল না করে আগে with() দিয়ে লোড করুন।

৩. Nested Eager Loading: with('author.profile') ব্যবহার করে সাব-রিলেশন লোড করুন।

৪. Constrained Eager Loading: রিলেশন লোড করার সময় with(['posts' => fn($q) => $q->where('active', 1)]) ব্যবহার করুন।

৫. Lazy Eager Loading: কন্ডিশনের ওপর ভিত্তি করে লোড করতে $model->load('relation') ব্যবহার করুন।

৬. withCount() ব্যবহার করুন: শুধু সংখ্যা জানতে পুরো রিলেশন লোড না করে withCount() ব্যবহার করুন।

৭. Avoid all(): বড় টেবিলে কখনো all() ব্যবহার করবেন না।

৮. Prevent Lazy Loading: ডেভেলপমেন্টে $model->preventLazyLoading() এনাবল রাখুন।

২. কলাম সিলেকশন ও মেমোরি ম্যানেজমেন্ট
৯. Select Only Needed Columns: select('id', 'name') ব্যবহার করুন, select * এড়িয়ে চলুন।

১০. pluck() এর ব্যবহার: শুধু একটি কলামের লিস্ট চাইলে get() এর বদলে pluck() ব্যবহার করুন।

১১. value() মেথড: একটিমাত্র রো-এর একটি কলাম চাইলে first()->email এর বদলে value('email') লিখুন।

১২. Memory Limit: বড় ডাটাবেস কুয়েরি করার আগে পিএইচপি মেমোরি লিমিট চেক করুন।

১৩. Avoid toArray() on Large Sets: বড় কালেকশনকে অ্যারেতে কনভার্ট করা মেমোরি ইনটেন্সিভ।

৩. বড় ডাটা প্রসেসিং (Batch Processing)
১৪. chunk() ব্যবহার করুন: হাজার হাজার ডাটা প্রসেস করতে chunk(100) ব্যবহার করুন।

১৫. chunkById(): আইডি ভিত্তিক চাঙ্ক করুন যাতে আপডেট করার সময় কোনো রেকর্ড মিস না হয়।

১৬. cursor() ব্যবহার করুন: পিএইচপি জেনারেটর ব্যবহার করে মেমোরি সাশ্রয়ীভাবে বড় ডাটা রিড করতে cursor() সেরা।

১৭. Lazy Collection: লারাভেলের LazyCollection ব্যবহার করে জটিল ডাটা প্রসেস করুন।

১৮. upsert() মেথড: একসাথে অনেক ডাটা ইনসার্ট এবং আপডেট করতে একটি মাত্র কুয়েরি upsert() ব্যবহার করুন।

১৯. Mass Insert: লুপের ভেতর create() না করে insert() ব্যবহার করুন (অ্যারে পাস করে)।

৪. ইনডেক্সিং ও ডাটাবেস স্ট্রাকচার
২০. Index Frequently Searched Columns: where ক্লজে থাকা কলামগুলোতে ডাটাবেস ইনডেক্স ব্যবহার করুন।

২১. Composite Indexes: একাধিক কলাম দিয়ে সার্চ করলে কম্পোজিট ইনডেক্স ব্যবহার করুন।

২২. Full-text Search: বড় টেক্সট সার্চের জন্য MATCH AGAINST বা লারাভেল স্কাউট (Scout) ব্যবহার করুন।

২৩. Integer over String: সার্চের জন্য স্ট্রিং এর বদলে ইন্টিজার কলাম (যেমন ID, Status Code) দ্রুত কাজ করে।

২৪. db:show ও db:table: লারাভেলের বিল্ট-ইন কমান্ড দিয়ে ডাটাবেসের সাইজ ও ইনডেক্স মনিটর করুন।

৫. অ্যাডভান্সড কুয়েরি টেকনিক
২৫. Subquery Selects: addSelect() ব্যবহার করে সাবকুয়েরি থেকে ডাটা আনুন।

২৬. Subquery Ordering: সাবকুয়েরি ব্যবহার করে সর্টিং করলে জয়েন কুয়েরির চেয়ে দ্রুত হতে পারে।

২৭. Join vs Relationship: খুব বড় ডাটার ক্ষেত্রে কখনো কখনো এলুকুয়েন্ট রিলেশনের চেয়ে Join কুয়েরি দ্রুত হয়।

২৮. exists() vs count(): রেকর্ড আছে কি না চেক করতে count() > 0 না লিখে exists() ব্যবহার করুন।

২৯. doesntExist(): রেকর্ড না থাকা নিশ্চিত করতে এটি ব্যবহার করুন।

৩০. whereIntegerInRaw(): বড় আইডি অ্যারে দিয়ে whereIn কুয়েরি করলে এটি দ্রুত কাজ করে।

৬. ক্যাশিং (Caching)
৩১. Remember Query Results: ঘনঘন পরিবর্তন হয় না এমন ডাটা Cache::remember() দিয়ে সেভ রাখুন।

৩২. Tagging Cache: রিলেটেড ডাটা ক্যাশ করতে ক্যাশ ট্যাগ ব্যবহার করুন।

৩৩. Cache Key Naming: ক্যাশ কি-এর জন্য মডেলের updated_at ব্যবহার করুন।

৩৪. Database Query Caching: ডাটাবেস লেভেলে ক্যাশিং এনাবল করুন (যেমন Redis)।

৭. অ্যাগ্রিগেটস ও কন্ডিশনালস
৩৫. when() এর সঠিক ব্যবহার: কন্ডিশনাল কুয়েরিতে ইফ-এলস না লিখে when() ব্যবহার করুন।

৩৬. Avoid count() in loops: লুপের ভেতর রিলেশন কাউন্ট করবেন না।

৩৭. withSum(), withAvg(): সরাসরি কুয়েরিতে যোগফল বা গড় বের করে আনুন।

৩৮. having vs where: গ্রুপ করা ডাটার ফিল্টারিংয়ে having ব্যবহার করুন।

৮. ডিলিট ও আপডেট অপ্টিমাইজেশন
৩৯. Mass Update: মডেল আপডেট না করে সরাসরি কুয়েরি বিল্ডার দিয়ে update() করুন।

৪০. Soft Deletes Performance: SoftDeletes ব্যবহার করলে ইনডেক্সে deleted_at কলাম রাখুন।

৪১. forceDelete(): অপ্রয়োজনীয় ডাটা পার্মানেন্টলি ডিলিট করুন ডাটাবেস পাতলা রাখতে।

৪২. Batch Delete: আইডি অ্যারে দিয়ে whereIn()->delete() করুন।

৯. ডাটাবেস ডিজাইন টিপস
৪৩. Normalization: ডাটা ডুপ্লিকেট এড়াতে ডাটাবেস নরমালাইজ করুন।

৪৪. Denormalization: খুব বেশি রিড হয় এমন অ্যাপে কিছু ডাটা ডিনরমালাইজ (ডুপ্লিকেট রাখা) করা পারফরম্যান্স বাড়াতে পারে।

৪৫. Use Appropriate Data Types: ছোট সংখ্যার জন্য tinyInteger, বড়র জন্য bigInteger ব্যবহার করুন।

৪৬. JSON Columns: খুব বেশি কাস্টম ফিল্ড থাকলে JSON কলাম ব্যবহার করুন।

১০. মনিটরিং ও টেস্টিং
৪৭. Laravel Telescope: কুয়েরি মনিটর করতে টেলিস্কোপ ব্যবহার করুন।

৪৮. toSql(): কুয়েরি চালানোর আগে toSql() দিয়ে SQL ফরম্যাট দেখে নিন।

৪৯. explain(): কুয়েরির শেষে explain() যোগ করে ডাটাবেস কীভাবে ডাটা খুঁজছে তা দেখুন।

৫০. Clockwork: ব্রাউজার থেকেই কুয়েরি পারফরম্যান্স চেক করুন।
