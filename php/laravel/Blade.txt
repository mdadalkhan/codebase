২. কন্ডিশনাল ডিরেক্টিভ (Conditional Directives)

@if($user->isAdmin) / @else / @endif: সাধারণ কন্ডিশন চেক করতে।

@isset($variable): ভেরিয়েবলটি সেট করা আছে কি না চেক করে।
@empty($data): ভেরিয়েবলটি খালি কি না চেক করে।


ডাটাবেজ থেকে আসা ডাটার লিস্ট দেখানোর জন্য এগুলো সেরা।

@forelse($users as $user)

লগইন করা ইউজারের জন্য কন্টেন্ট হাইড বা শো করতে এগুলো ব্যবহার করা হয়।

৩. লুপ ডিরেক্টিভ (Loop Directives)
ডাটাবেজ থেকে আসা ডাটার লিস্ট দেখানোর জন্য এগুলো সেরা।

৪. অথেন্টিকেশন ডিরেক্টিভ (Auth Directives)
লগইন করা ইউজারের জন্য কন্টেন্ট হাইড বা শো করতে এগুলো ব্যবহার করা হয়।
@auth: শুধু লগইন করা ইউজাররা এর ভেতরের অংশ দেখতে পাবে।
@guest: শুধু যারা লগইন করেনি (অতিথি), তারা এটি দেখতে পাবে।


৫. অন্যান্য প্রয়োজনীয় ডিরেক্টিভ
@csrf: ফর্ম সাবমিট করার সময় সিকিউরিটির জন্য এটি মাস্ট। এটি একটি হিডেন ইনপুট ফিল্ড তৈরি করে।
@method('PUT'): HTML ফর্ম শুধু GET/POST সাপোর্ট করে। অন্য মেথড (যেমন: PUT/DELETE) ব্যবহারের জন্য এটি লাগে।
@stack('scripts') এবং @push('scripts'): লেআউটের এক জায়গায় স্ক্রিপ্ট বা স্টাইল জমা করার জন্য এবং পেজ থেকে তা পাঠানোর জন্য।


লারাভেলের @stack এবং @push ডিরেক্টিভ দুটি বড় লেআউট ম্যানেজ করার জন্য অত্যন্ত শক্তিশালী। এগুলোকে সহজভাবে বুঝতে হলে নিচের ব্যাখ্যাটি লক্ষ্য করুন:

@stack কী এবং কেন প্রয়োজন?
সাধারণত আমরা মাস্টার লেআউটে সব সিএসএস বা জেএস (JS) ফাইল লোড করি। কিন্তু কিছু স্ক্রিপ্ট থাকে যা শুধু নির্দিষ্ট একটি পেজে প্রয়োজন (যেমন: আপনার হোস্টেল ম্যানেজমেন্টের জন্য কোনো চার্ট বা ক্যালেন্ডার)।

সব স্ক্রিপ্ট মেইন লেআউটে রাখলে সাইট স্লো হয়ে যায়। এই সমস্যা সমাধানের জন্য আমরা @stack ব্যবহার করি। এটি একটি "খালি ড্রয়ার" বা কন্টেইনারের মতো কাজ করে।

লারাভেল ব্লেড (Laravel Blade) শুধুমাত্র একটি টেম্প্লেটিং ইঞ্জিন নয়, বরং এটি আপনার অ্যাপ্লিকেশনের ফ্রন্ট-এন্ড লজিককে ক্লিন এবং অর্গানাইজড রাখার একটি শক্তিশালী মাধ্যম। একটি প্রফেশনাল এবং স্কেলেবল অ্যাপ্লিকেশন তৈরির জন্য নিচে দেওয়া গাইডলাইনটি অনুসরণ করতে পারেন:

১. কম্পোনেন্ট-বেসড আর্কিটেকচার (Component-based)
আধুনিক লারাভেলে @include এর চেয়ে Blade Components ব্যবহার করা অনেক বেশি প্রফেশনাল। এটি কোডকে মডুলার এবং রিইউজেবল করে।

Anonymous Components: ছোট ছোট এলিমেন্টের জন্য (যেমন: বাটন, ইনপুট)।

HTML

<button {{ $attributes->merge(['class' => 'bg-blue-500 text-white p-2']) }}>
    {{ $slot }}
</button>
ব্যাবহার: <x-button class="mt-4">সেভ করুন</x-button>

২. লেআউট ম্যানেজমেন্ট (Layouts)
সব পেজের জন্য একটি মাস্টার লেআউট ব্যবহার করুন। @extends এর বদলে এখন <x-layout> সলট (Slot) সিস্টেম ব্যবহার করা বেশি জনপ্রিয়।

৩. ডিরেক্টিভস এর সঠিক ব্যবহার
ব্লেড ডিরেক্টিভগুলো আপনার এইচটিএমএলকে ক্লিন রাখে।

Empty State: লুপ চালানোর সময় যদি ডাটা না থাকে:

HTML

@forelse($users as $user)
    <li>{{ $user->name }}</li>
@empty
    <p>কোনো ইউজার পাওয়া যায়নি।</p>
@endforelse
Auth Checks: @auth এবং @guest ব্যবহার করুন।

Custom Directives: আপনার যদি বারবার কোনো নির্দিষ্ট ফরমেট (যেমন কারেন্সি ফরমেটিং) ব্যবহার করতে হয়, তবে AppServiceProvider-এ কাস্টম ডিরেক্টিভ তৈরি করে নিন।

৪. সিকিউরিটি (XSS Protection)
ব্লেড ডিফল্টভাবে {{ $data }} ব্যবহারের মাধ্যমে ডাটাকে এসকেপ (Escape) করে। কিন্তু যদি আপনি কাঁচা এইচটিএমএল (Raw HTML) দেখাতে চান, তবেই কেবল {!! $data !!} ব্যবহার করবেন।

সতর্কতা: আপনার সেভ করা পলিসি অনুযায়ী, স্ক্রিপ্ট ইনজেকশন রোধে এবং Same-Origin নিশ্চিত করতে কখনোই ইউজার ইনপুটকে {!! !!} এর ভেতর দেবেন না।

৫. পারফরম্যান্স অপ্টিমাইজেশন
@once: যদি আপনার কম্পোনেন্টের ভেতর নির্দিষ্ট কোনো সিএসএস বা জেএস থাকে যা একবারই লোড হওয়া দরকার, তবে @once ব্যবহার করুন।

View Caching: প্রোডাকশনে অবশ্যই ভিউ ক্যাশ করে রাখবেন: php artisan view:cache

৬. স্ট্যাকস এবং পুশ (Stacks & Push)
লেআউটের নির্দিষ্ট জায়গায় (যেমন ফুটারের ঠিক আগে) স্ক্রিপ্ট পাঠানোর জন্য @stack এবং @push ব্যবহার করুন। এটি পেজ লোডিং স্পিড ঠিক রাখতে সাহায্য করে।

একটি প্রফেশনাল ব্লেড স্ট্রাকচার উদাহরণ:
HTML

<x-app-layout>
    <x-slot:title>ড্যাশবোর্ড</x-slot>

    <div class="grid grid-cols-3 gap-4">
        @foreach($stats as $stat)
            <x-card :title="$stat->title" :value="$stat->value" />
        @endforeach
    </div>

    @push('scripts')
        <script src="https://cdn.example.com/chart.js"></script>
    @endpush
</x-app-layout>
কেন এই পদ্ধতিটি সেরা?
১. Readable: কোড পড়তে সুবিধা হয়। ২. Maintainable: এক জায়গায় চেঞ্জ করলে সব জায়গায় আপডেট হয়। ৩. Testable: ছোট ছোট কম্পোনেন্টগুলো আলাদাভাবে টেস্ট করা যায়।

আপনি কি আপনার প্রজেক্টের জন্য কোনো নির্দিষ্ট ক্রুড (CRUD) ইন্টারফেসের ব্লেড ডিজাইন দেখতে চান? আমি সেটির একটি পূর্ণাঙ্গ কোড স্ট্রাকচার লিখে দিতে পা

লারাভেল ব্লেডকে প্রফেশনাল এবং এন্টারপ্রাইজ লেভেলে নিয়ে যাওয়ার জন্য ১০০টি টিপস নিচে ক্যাটাগরি অনুযায়ী সাজিয়ে দেওয়া হলো:

১. আর্কিটেকচার ও লেআউট (১-২০)
১. সব সময় একটি app.blade.php মাস্টার লেআউট ফাইল ব্যবহার করুন। ২. @extends এর বদলে আধুনিক Blade Components (Slots) ব্যবহার করুন। ৩. হেড সেকশনে মেটা ট্যাগগুলোর জন্য আলাদা একটি ছোট কম্পোনেন্ট তৈরি করুন। ৪. সিএসএস এবং জেএস ফাইলের জন্য @stack এবং @push ব্যবহার করুন। ৫. নেভিগেশন বারের জন্য আলাদা ব্লেড কম্পোনেন্ট তৈরি করুন। ৬. ফুটারের জন্য আলাদা কম্পোনেন্ট রাখুন। ৭. সাইডবারকে কন্ডিশনাল সলট হিসেবে ডিফাইন করুন। ৮. লেআউট ফাইলে lang অ্যাট্রিবিউট ডায়নামিক রাখুন: lang="{{ str_replace('_', '-', app()->getLocale()) }}"। ৯. ডাইনামিক টাইটেলের জন্য <title>{{ $title ?? 'Default Title' }}</title> ব্যবহার করুন। ১০. এসইও (SEO) মেটা ট্যাগের জন্য আলাদা একটি কম্পোনেন্ট ফাইল ব্যবহার করুন। ১১. বডি ক্লাসের জন্য @stack('body-class') ব্যবহার করুন। ১২. থিম মোড (Light/Dark) হ্যান্ডেল করার লজিক লেআউটের একদম শুরুতে রাখুন। ১৩. পেজ লোডার বা স্পিনারকে লেআউটে একবারই ডিফাইন করুন। ১৪. নটিফিকেশন (Toast/Alert) এর জন্য গ্লোবাল স্ট্যাক ব্যবহার করুন। ১৫. মোডাল (Modal) এর জন্য বডির শেষে একটি স্ট্যাক রাখুন। ১৬. থার্ড পার্টি স্ক্রিপ্ট (Google Analytics) আলাদা ফাইলে রেখে @include করুন। ১৭. সিএসএস ভেরিয়েবলগুলো স্টাইল স্ট্যাকের শুরুতে ডিফাইন করুন। ১৮. রাইট-টু-লেফট (RTL) সাপোর্টের জন্য কন্ডিশনাল ক্লাস ব্যবহার করুন। ১৯. কন্টেন্ট এরিয়ার জন্য একটি মেইন র‍্যাপার কম্পোনেন্ট ব্যবহার করুন। ২০. এরর পেজগুলোর (404, 500) জন্য আলাদা মিনিমাল লেআউট ব্যবহার করুন।

২. কম্পোনেন্ট এবং রিইউজেবিলিটি (২১-৪০)
২১. প্রতিটি বাটনের জন্য একটি গ্লোবাল <x-button /> কম্পোনেন্ট বানান। ২২. ইনপুট ফিল্ডের জন্য <x-input /> কম্পোনেন্ট ব্যবহার করুন যাতে এরর মেসেজ ইনক্লুডেড থাকে। ২৩. ডাটা টেবিলকে ছোট ছোট ব্লেড কম্পোনেন্টে ভাগ করুন। ২৪. ড্রপডাউন মেনুকে রিইউজেবল করতে alpine.js এর সাথে ইন্টিগ্রেট করুন। ২৫. কার্ড এলিমেন্টের জন্য <x-card /> ব্যবহার করুন। ২৬. ইমেজ সোর্স বা আল্ট ট্যাগের জন্য প্রপস (Props) ব্যবহার করুন। ২৭. ডিফল্ট ভ্যালু সেট করতে @props(['type' => 'button']) ব্যবহার করুন। ২৮. ক্লাস মার্জ করার জন্য {{ $attributes->merge(['class' => 'default-class']) }} ব্যবহার করুন। ২৯. আইকন ব্যবহারের জন্য একটি ডেডিকেটেড আইকন কম্পোনেন্ট সিস্টেম তৈরি করুন। ৩০. ব্যাজ বা স্ট্যাটাস দেখানোর জন্য কন্ডিশনাল কালার কম্পোনেন্ট তৈরি করুন। ৩১. ফর্ম লেবেলের জন্য আলাদা ছোট কম্পোনেন্ট রাখুন। ৩২. চেকবক্স এবং রেডিও বাটনের জন্য আলাদা স্টাইলড কম্পোনেন্ট। ৩৩. পেজিনেশন ভিউ কাস্টমাইজ করে resources/views/vendor এ রাখুন। ৩৪. টেক্সট এডিটর বা রিচ টেক্সট ফিল্ডের জন্য কম্পোনেন্ট র‍্যাপার ব্যবহার করুন। ৩৫. ব্রেডক্রাম্ব (Breadcrumbs) এর জন্য ডাইনামিক কম্পোনেন্ট তৈরি করুন। ৩৬. ফাইল আপলোডারের জন্য জাভাস্ক্রিপ্ট সহ কম্পোনেন্ট তৈরি করুন। ৩৭. ইউজার অ্যাভাটার দেখানোর জন্য একটি হেল্পার কম্পোনেন্ট। ৩৮. স্কেলিটন লোডিং (Skeleton Loading) এর জন্য ব্লেড কম্পোনেন্ট ব্যবহার করুন। ৩৯. টুলটিপ (Tooltip) এর জন্য অ্যাট্রিবিউট পাসিং ব্যবহার করুন। ৪০. সার্চ বারের জন্য একটি গ্লোবাল কম্পোনেন্ট রাখুন।

৩. লজিক এবং ডিরেক্টিভস (৪১-৬০)
৪১. @if এর ভেতর জটিল লজিক না লিখে কন্ট্রোলার বা মডেলে চেক করুন। ৪২. লুপের ডাটা না থাকলে @foreach এর বদলে @forelse ব্যবহার করুন। ৪৩. অথেন্টিকেশন চেকের জন্য @auth এবং @guest ব্যবহার করুন। ৪৪. ইউজারের পারমিশন চেকের জন্য @can এবং @cannot ব্যবহার করুন। ৪৫. এনভায়রনমেন্ট চেক করতে @env('production') ব্যবহার করুন। ৪৬. সেকশন বা স্ট্যাক একবার লোড করতে @once ডিরেক্টিভ ব্যবহার করুন। ৪৭. কন্ডিশনাল ক্লাস যোগ করতে @class(['font-bold' => $isActive]) ব্যবহার করুন। ৪৮. চেকড বা সিলেক্টেড অ্যাট্রিবিউটের জন্য @checked($value) এবং @selected($value) ব্যবহার করুন। ৪৯. ডিজেবল্ড অ্যাট্রিবিউটের জন্য @disabled($condition) ব্যবহার করুন। ৫০. পিএইচপি কোড লিখতে হলে সরাসরি @php ... @endphp ব্লক ব্যবহার করুন। ৫১. কাস্টম ব্লেড ডিরেক্টিভ তৈরি করুন (যেমন: @currency($amount))। ৫২. ইউজারের প্রোফাইল পিকচার না থাকলে প্লেসহোল্ডার দেখাতে কন্ডিশনাল লজিক। ৫৩. ডেট ফরমেট করার জন্য ব্লেডে সরাসরি কার্বন ($date->format()) ব্যবহার করুন। ৫৪. জাভাস্ক্রিপ্ট অবজেক্ট পাস করতে @json($data) ব্যবহার করুন। ৫৫. সিএসআরএফ সুরক্ষার জন্য ফর্মে অবশ্যই @csrf ব্যবহার করবেন। ৫৬. স্পুফিং এর জন্য @method('PUT') বা @method('DELETE') ব্যবহার করুন। ৫৭. এরর মেসেজ দেখাতে @error('fieldname') ডিরেক্টিভ ব্যবহার করুন। ৫৮. মাল্টি-ল্যাঙ্গুয়েজ সাপোর্টের জন্য {{ __('messages.welcome') }} ব্যবহার করুন। ৫৯. রিইউজেবল এইচটিএমএল ব্লকের জন্য @fragment ব্যবহার করুন। ৬০. জাভাস্ক্রিপ্ট ভেরিয়েবল হিসেবে ব্লেড ডাটা নিতে window.data = @js($data); ব্যবহার করুন।

৪. ডাটা ও সিকিউরিটি (৬১-৮০)
৬১. ইউজার ইনপুট প্রিন্ট করতে সবসময় {{ $variable }} ব্যবহার করুন (XSS সুরক্ষা)। ৬২. এইচটিএমএল রেন্ডার করতে হলে {!! $variable !!} খুব সাবধানে ব্যবহার করুন। ৬৩. আপনার নির্দেশিত Same-Origin পলিসি অনুযায়ী এক্সটার্নাল স্ক্রিপ্ট ইনজেকশন থেকে বিরত থাকুন। ৬৪. ইমেজ এবং অ্যাসেট লোড করতে asset() বা vite() হেল্পার ব্যবহার করুন। ৬৫. রাউটিং এর জন্য ইউআরএল হার্ডকোড না করে route('name') ব্যবহার করুন। ৬৬. অনেক ডাটা থাকলে ব্লেডে সরাসরি কোয়েরি না করে কন্ট্রোলার থেকে পাস করুন। ৬৭. মডেল রিলেশনশিপ লোড করার সময় Eager Loading নিশ্চিত করুন যাতে N+1 সমস্যা না হয়। ৬৮. সেশন মেসেজ দেখানোর জন্য একটি গ্লোবাল অ্যালার্ট ফাইল ইনক্লুড করুন। ৬৯. ফর্ম সাবমিট করার সময় ডাবল ক্লিক রোধে জাভাস্ক্রিপ্ট যুক্ত করুন। ৭০. সেনসিটিভ ডাটা (যেমন পাসওয়ার্ড) কখনো ব্লেডে সরাসরি দেখাবেন না। ৭১. ইউআরএল জেনারেট করতে secure_url() ব্যবহার করুন যদি এইচটিটিপিএস দরকার হয়। ৭২. ওল্ড ইনপুট ডাটা রিটেইন করতে value="{{ old('name') }}" ব্যবহার করুন। ৭৩. কারেন্সি বা বড় নাম্বার ফরমেটিং এর জন্য ব্লেড হেল্পার ব্যবহার করুন। ৭৪. লম্বা টেক্সট ট্রানকেট করতে Str::limit() ব্যবহার করুন। ৭৫. কন্টেন্ট সিকিউরিটি পলিসি (CSP) হেডার ব্লেড হেডারে কনফিগার করুন। ৭৬. জাভাস্ক্রিপ্টে ব্লেড ভেরিয়েবল নেওয়ার সময় addslashes খেয়াল রাখুন। ৭৭. কোনো ডাটা নাল হতে পারলে সেফ নেভিগেশন {{ $user?->name }} ব্যবহার করুন। ৭৮. ব্লেডে কাঁচা এসকিউএল কোয়েরি লেখা সম্পূর্ণ নিষিদ্ধ করুন। ৭৯. ফাইল সাইজ বা টাইপ দেখানোর জন্য ফরমেটিং হেল্পার ব্যবহার করুন। ৮০. এপিআই রেসপন্স ব্লেডে রেন্ডার করতে লুপের ইনডেক্সিং খেয়াল রাখুন।

৫. পারফরম্যান্স ও প্রোডাকশন (৮১-১০০)
৮১. প্রোডাকশনে ভিউ ক্যাশ করতে php artisan view:cache কমান্ড চালান। ৮২. বড় ব্লেড ফাইলগুলোকে ছোট ছোট পার্শিয়াল ফাইলে ভাগ করুন। ৮৩. ইমেজের জন্য loading="lazy" অ্যাট্রিবিউট ব্যবহার করুন। ৮৪. সিএসএস এবং জেএস কমবাইন করতে Laravel Vite ব্যবহার করুন। ৮৫. অনেকগুলো @include এর বদলে একটি বড় কম্পোনেন্ট ব্যবহার করা দ্রুততর। ৮৬. আনইউজড সিএসএস রিমুভ করতে PurgeCSS ব্যবহার করুন। ৮৭. কন্ডিশনাল লোডিং এর জন্য লাইভওয়্যার (Livewire) ব্যবহার করুন। ৮৮. পেজ লোড ফাস্ট করতে wire:navigate (Livewire 3) ব্যবহার করুন। ৮৯. ফন্টগুলো লোকাল সার্ভারে হোস্ট করুন এক্সটার্নাল সিডিএন এর বদলে। ৯০. আইকন ফন্ট (FontAwesome) এর বদলে SVG আইকন ব্যবহার করুন। ৯১. এসভিজি সরাসরি এইচটিএমএল এ না রেখে ব্লেড কম্পোনেন্ট হিসেবে রাখুন। ৯২. প্রোডাকশনে ডিবাগবার (Debugbar) বন্ধ রাখুন। ৯৩. লোকাল ডেভেলপমেন্টে php artisan view:clear ব্যবহার করে ক্যাশ ক্লিন রাখুন। ৯৪. হেভি জাভাস্ক্রিপ্ট লাইব্রেরি শুধু প্রয়োজনীয় পেজে @push করুন। ৯৫. রিডান্ডেন্ট কোড এড়াতে BaseComponent প্যাটার্ন অনুসরণ করুন। ৯৬. ভিউ ফাইলের নাম ছোট হাতের এবং হাইফেন যুক্ত রাখুন (যেমন: user-profile.blade.php)। ৯৭. ফোল্ডার স্ট্রাকচার মডিউল অনুযায়ী সাজান (যেমন: views/admin/users/index.blade.php)। ৯৮. কমেন্ট করার জন্য {{-- comment --}} ব্যবহার করুন যাতে সেটি ব্রাউজারে না যায়। ৯৯. কোড রিডিবিলিটি বাড়াতে সঠিক ইনডেন্টেশন বজায় রাখুন। ১০০. নিয়মিত আপনার ভিউ ফাইলগুলো রিফ্যাক্টর করুন।

লাইভওয়্যার (Livewire) আধুনিক লারাভেল ইকোসিস্টেমের একটি জাদুকরী টুল। এটি আপনাকে জাভাস্ক্রিপ্ট না লিখেই একটি সিঙ্গেল পেজ অ্যাপ্লিকেশন (SPA) এর মতো রিয়েল-টাইম অভিজ্ঞতা দেয়।

প্রফেশনাল লেভেলে লাইভওয়্যার ৩ ব্যবহারের ১০০টি টিপস নিচে ৫টি ক্যাটাগরিতে দেওয়া হলো:

১. আর্কিটেকচার ও কম্পোনেন্ট ডিজাইন (১-২০)
১. সব সময় Full-page components ব্যবহার করার চেষ্টা করুন যাতে রাউটিং সহজ হয়। ২. রিইউজেবল এলিমেন্টের জন্য Inline components তৈরি করুন। ৩. বড় কম্পোনেন্টকে ছোট ছোট সাব-কম্পোনেন্টে ভাগ করুন। ৪. কম্পোনেন্টের প্রপার্টিগুলোকে protected বা private রাখুন যদি সেগুলো ভিউতে দরকার না হয়। ৫. ডাটা ট্রান্সফারের জন্য DTO (Data Transfer Objects) ব্যবহার করুন। ৬. সব কম্পোনেন্টে একই লেআউট চাইলে একটি BaseComponent ক্লাস তৈরি করে তা এক্সটেন্ড করুন। ৭. টাইটেল সেট করতে #[Title('Page Name')] অ্যাট্রিবিউট ব্যবহার করুন। ৮. লেআউট ডিফাইন করতে #[Layout('layouts.app')] ব্যবহার করুন। ৯. ডাইনামিক ডাটার জন্য লাইভওয়্যারের Computed Properties ($this->property) ব্যবহার করুন। ১০. কম্পোনেন্ট মাউন্ট করার সময় শুধু প্রয়োজনীয় ডাটা লোড করুন। ১১. এডিট ফর্মের জন্য সরাসরি Eloquent Model বাইন্ডিং ব্যবহার করুন। ১২. ফর্ম লজিক আলাদা করতে Form Objects ব্যবহার করুন (লাইভওয়্যার ৩-এর সেরা ফিচার)। ১৩. কম্পোনেন্টের ভেতর সরাসরি কুয়েরি না লিখে সার্ভিস ক্লাসে রাখুন। ১৪. খুব বেশি প্রপার্টি পাবলিক করবেন না, এতে সিকিউরিটি রিস্ক বাড়ে। ১৫. কম্পোনেন্ট ডিলিট করার সময় কনফার্মেশন মোডাল ব্যবহার করুন। ১৬. ডাটা টেবিলের জন্য সার্চ এবং সর্টিং লজিক ট্রেইট (Trait) হিসেবে রাখুন। ১৭. সব সময় wire:key ব্যবহার করুন লুপের ভেতর পারফরম্যান্স ঠিক রাখতে। ১৮. গ্লোবাল ইভেন্টের জন্য লিসেনারগুলোকে আলাদা মেথডে সাজান। ১৯. পেজিনেশনের জন্য লাইভওয়্যারের WithPagination ট্রেইট ব্যবহার করুন। ২০. উইজেট টাইপ কম্পোনেন্টের জন্য লেজি লোডিং (lazy: true) এনাবল করুন।

২. রিয়েল-টাইম ফিচার ও ইন্টারঅ্যাকশন (২১-৪০)
২১. ইনপুট সিঙ্ক করার জন্য wire:model ব্যবহার করুন। ২২. নেটওয়ার্ক রিকোয়েস্ট কমাতে wire:model.blur বা wire:model.live.debounce.500ms ব্যবহার করুন। ২৩. রিয়েল-টাইম ভ্যালিডেশনের জন্য updated হুক ব্যবহার করুন। ২৪. পেজ রিলোড ছাড়া নেভিগেশনের জন্য wire:navigate ব্যবহার করুন। ২৫. মাউস হোভার করলে ডাটা প্রিফেচ করতে wire:navigate.hover ব্যবহার করুন। ২৬. কোনো অ্যাকশন চলাকালীন ইউজারকে বোঝাতে wire:loading ব্যবহার করুন। ২৭. নির্দিষ্ট বাটনের জন্য লোডিং স্টেট দেখাতে wire:loading.target="save" ব্যবহার করুন। ২৮. অফলাইন স্ট্যাটাস হ্যান্ডেল করতে wire:offline ডিরেক্টিভ ব্যবহার করুন। ২৯. ফাইল আপলোডের সময় প্রগ্রেস বার দেখাতে লাইভওয়্যারের ডিফল্ট জাভাস্ক্রিপ্ট ইভেন্ট ব্যবহার করুন। ৩০. কম্পোনেন্টের মধ্যে কমিউনিকেশনের জন্য $dispatch ব্যবহার করুন। ৩১. ব্রাউজার ইভেন্ট পাঠাতে $this->dispatch('event-name') ব্যবহার করুন। ৩২. ইভেন্ট লিসেনারের জন্য #[On('event-name')] অ্যাট্রিবিউট ব্যবহার করুন। ৩৩. ইউআরএল কুয়েরি স্ট্রিং আপডেট রাখতে #[Url] অ্যাট্রিবিউট ব্যবহার করুন। ৩৪. পোলিং (Polling) এর মাধ্যমে ডাটা অটো-রিফ্রেশ করতে wire:poll.5s ব্যবহার করুন। ৩৫. কন্ডিশনাল পোলিং ব্যবহার করুন যাতে ট্যাব ইনঅ্যাক্টিভ থাকলে রিকোয়েস্ট না যায়। ৩৬. জাভাস্ক্রিপ্ট থেকে লাইভওয়্যার মেথড কল করতে $wire.call() ব্যবহার করুন। ৩৭. এন্টার কি প্রেস করলে ফর্ম সাবমিট করতে wire:keydown.enter ব্যবহার করুন। ৩৮. ক্লিক ইভেন্টে প্রিভেন্ট মডিফায়ার ব্যবহার করুন: wire:click.prevent । ৩৯. একবার মাত্র ইভেন্ট ট্রিগার করতে .once মডিফায়ার ব্যবহার করুন। ৪০. স্ক্রল পজিশন ধরে রাখতে wire:persist ব্যবহার করুন।

৩. সিকিউরিটি ও পারফরম্যান্স (৪১-৬০)
৪১. পাবলিক প্রপার্টিতে কখনো সেনসিটিভ ডাটা (যেমন: API Key) রাখবেন না। ৪২. ইউজার যা ইনপুট দিচ্ছে তা সবসময় সার্ভার সাইডে ভ্যালিডেট করুন। ৪৩. Same-Origin পলিসি নিশ্চিত করতে লাইভওয়্যার কনফিগারেশনে সঠিক ডোমেইন সেট করুন। ৪৪. কুয়েরি রেজাল্ট ক্যাশ করতে লারাভেলের ক্যাশ সিস্টেম ব্যবহার করুন। ৪৫. বড় ডাটা সেটের জন্য সবসময় SimplePagination ব্যবহার করুন। ৪৬. অপ্রয়োজনীয় রেন্ডারিং রোধ করতে #[Locked] অ্যাট্রিবিউট ব্যবহার করুন। ৪৭. অথরাইজেশন চেক করতে মেথডের শুরুতে $this->authorize() কল করুন। ৪৮. মাল্টিপল ফাইল আপলোডের সময় সাইজ লিমিট সার্ভার সাইডে চেক করুন। ৪৯. স্প্যাম রোধ করতে ফর্মের সাথে হানিপট (Honeypot) বা রেট লিমিটিং ব্যবহার করুন। ৫০. জাভাস্ক্রিপ্ট ইনজেকশন রোধে ডাটা ডিসপ্লে করার সময় ডাবল কার্লি ব্র্যাকেট {{ }} ব্যবহার করুন। ৫১. পারফরম্যান্স বাড়াতে কম্পোনেন্ট লেভেলে ডাটা মেমোইজেশন (Memoization) করুন। ৫২. বড় লিস্ট রেন্ডার করার সময় wire:ignore ব্যবহার করুন যদি সেখানে জাভাস্ক্রিপ্ট লাইব্রেরি থাকে। ৫৩. এপিআই কল করার সময় টাইমআউট হ্যান্ডেল করুন। ৫৪. প্রোডাকশনে debug মোড বন্ধ রাখুন। ৫৫. অপ্রয়োজনীয় ডাটা মাউন্ট মেথড থেকে ভিউতে পাঠাবেন না। ৫৬. লাইভওয়্যার স্ক্রিপ্টগুলো ফুটারের শেষে লোড করুন। ৫৭. অ্যাসেট লোড করার সময় ভার্সনিং (Versioning) ব্যবহার করুন। ৫৮. বড় ইমেজের বদলে থাম্বনেইল ব্যবহার করুন। ৫৯. মেমোরি লিক রোধ করতে জাভাস্ক্রিপ্ট ইভেন্ট লিসেনারগুলো destroying হুকে রিমুভ করুন। ৬০. কন্টেন্ট সিকিউরিটি পলিসি (CSP) হেডার কঠোরভাবে মেনটেইন করুন।

৪. জাভাস্ক্রিপ্ট ও অ্যালপাইন ইন্টিগ্রেশন (৬১-৮০)
৬১. ছোটখাটো UI পরিবর্তনের জন্য লাইভওয়্যারের বদলে Alpine.js ব্যবহার করুন। ৬২. লাইভওয়্যার এবং অ্যালপাইনের মধ্যে ডাটা শেয়ার করতে @entangle ব্যবহার করুন। ৬৩. থার্ড পার্টি জেএস লাইব্রেরি (যেমন: Select2, Flatpickr) ব্যবহারের সময় wire:ignore ব্যবহার করুন। ৬৪. ডম (DOM) সরাসরি চেঞ্জ না করে অ্যালপাইন স্টেট চেঞ্জ করুন। ৬৫. লাইভওয়্যার রেন্ডার হওয়ার পর জেএস কোড রান করতে Livewire.hook ব্যবহার করুন। ৬৬. কোনো এলিমেন্টকে জাভাস্ক্রিপ্ট থেকে রেফারেন্স করতে x-ref ব্যবহার করুন। ৬৭. এনিমেশনের জন্য অ্যালপাইনের x-transition ব্যবহার করুন। ৬৮. স্লাইডার বা ড্রপডাউনের জন্য অ্যালপাইন সবথেকে ফাস্ট। ৬৯. গ্লোবাল স্টোর ম্যানেজ করতে Alpine.store ব্যবহার করুন। ৭০. লাইভওয়্যার মেথড থেকে রিটার্ন করা ভ্যালু অ্যালপাইন দিয়ে রিসিভ করুন। ৭১. জেএস স্ক্রিপ্টগুলোকে ব্লকিং থেকে বাঁচাতে defer ব্যবহার করুন। ৭২. কাস্টম ইভেন্ট বাবিলিং (Bubbling) হ্যান্ডেল করুন। ৭৩. ফ্লোটিং এলিমেন্টের জন্য Floating UI লাইব্রেরি ইন্টিগ্রেট করুন। ৭৪. ড্র্যাগ অ্যান্ড ড্রপ ফিচারের জন্য SortableJS এর সাথে লাইভওয়্যার সিঙ্ক করুন। ৭৫. চার্ট দেখানোর জন্য Chart.js এর সাথে রিঅ্যাক্টিভ ডাটা বাইন্ডিং করুন। ৭৬. কপি-টু-ক্লিপবোর্ড ফিচারের জন্য অ্যালপাইন ম্যাজিক প্রপার্টি ব্যবহার করুন। ৭৭. কিবোর্ড শর্টকাট যোগ করতে x-on:keydown.window ব্যবহার করুন। ৭৮. মোডাল ওপেন থাকলে স্ক্রল লক করতে অ্যালপাইন ব্যবহার করুন। ৭৯. ইমেজ ক্রপিং এর জন্য Cropper.js ব্যবহার করে বেস৬৪ ডাটা লাইভওয়্যারে পাঠান। ৮০. নটিফিকেশন সাউন্ডের জন্য ব্রাউজার অডিও এপিআই ব্যবহার করুন।

৫. টেস্টিং ও বেস্ট প্র্যাকটিস (৮১-১০০)
৮১. প্রতিটি কম্পোনেন্টের জন্য অবশ্যই Feature Test লিখুন। ৮২. লাইভওয়্যারের বিল্ট-ইন টেস্টিং মেথড (assertSee, call, set) ব্যবহার করুন। ৮৩. ভ্যালিডেশন এরর চেক করতে assertHasErrors ব্যবহার করুন। ৮৪. ইউজার অথরাইজেশন টেস্ট করতে actingAs ব্যবহার করুন। ৮৫. রিডাইরেক্ট চেক করতে assertRedirect ব্যবহার করুন। ৮৬. ইভেন্ট ডিসপ্যাচ হয়েছে কি না তা টেস্ট করুন। ৮৭. কোড রিভিউ করার সময় N+1 কোয়েরি চেক করুন। ৮৮. বড় প্রজেক্টে কম্পোনেন্টগুলোকে ফোল্ডার অনুযায়ী সাজান (যেমন: Admin/User/Create)। ৮৯. কমন লজিকের জন্য কাস্টম ডিরেক্টিভ বা সার্ভিস ক্লাস ব্যবহার করুন। ৯০. কম্পোনেন্টের নাম সব সময় অর্থবহ এবং ইউনিক রাখুন। ৯১. ডেভেলপমেন্টের সময় Laravel Debugbar দিয়ে রিকোয়েস্ট সংখ্যা মনিটর করুন। ৯২. লাইভওয়্যার ৩-এর নতুন wire:stream ফিচার ব্যবহার করুন বড় রেসপন্সের জন্য। ৯৩. এরর পেজগুলো লাইভওয়্যার স্টাইলে কাস্টমাইজ করুন। ৯৪. ডকুমেন্টেশন ফলো করে লেটেস্ট ফিচারগুলো আপডেট রাখুন। ৯৫. গিটহাবে লাইভওয়্যারের অফিশিয়াল ডিসকাশন ফোরাম ফলো করুন। ৯৬. কোড ফরম্যাটিং এর জন্য Pint বা PHP CS Fixer ব্যবহার করুন। ৯৭. টাইপ সেফটি নিশ্চিত করতে পিএইচপি Strict Types ব্যবহার করুন। ৯৮. ইউজারের ফিডব্যাক পেতে সাকসেস মেসেজগুলো প্রফেশনাল রাখুন। ৯৯. কমপ্লেক্স কুয়েরির জন্য লারাভেল Scopes ব্যবহার করুন। ১০০. সবসময় শেখার মানসিকতা রাখুন এবং নতুন ভার্সনের ব্রেকিং চেঞ্জগুলো খেয়াল করুন।

এই টিপসগুলো অনুসরণ করলে আপনার লাইভওয়্যার অ্যাপ্লিকেশন হবে সুপার ফাস্ট, সিকিউর এবং মেইনটেনেবল।
