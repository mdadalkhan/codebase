PHP (8+) – CORE CONCEPTS & BEST PRACTICES
Professional Summary Notes (Printable)
1. PHP ENGINEER MINDSET

PHP একটি টুল, সলিউশন না

সমস্যা → ডিজাইন → কোড → টেস্ট → মেইনটেইন

ফিচার জানার চেয়ে সঠিক সিদ্ধান্ত নেওয়া বেশি গুরুত্বপূর্ণ

Readable code > Clever code

Framework ছাড়াও code টিকে থাকতে হবে

2. CLASS & OBJECT (CORE FOUNDATION)
Class

Class হলো blueprint বা design

ডেটা (property) + আচরণ (method) define করে

নিজ দায়িত্ব নিজে বহন করবে (SRP)

class User {
    public function changePassword(): void {}
}

Object

Class থেকে তৈরি হওয়া বাস্তব instance

System আসলে object-এর interaction

$user = new User();

Best Practices

Class একটি কাজ করবে

Constructor ছাড়া object incomplete হবে না

final ব্যবহার করুন যেখানে inheritance দরকার নেই

Public property কম ব্যবহার করুন

Immutable object পছন্দ করুন

3. CONSTRUCTOR & IMMUTABILITY
final readonly class Email {
    public function __construct(
        public string $value
    ) {}
}


Constructor mandatory state নিশ্চিত করে

Readonly property accidental mutation বন্ধ করে

DTO ও Value Object এর জন্য আদর্শ

4. FUNCTION vs METHOD
বিষয়	Function	Method
State	Stateless	Object state aware
ব্যবহার	Helper	Domain logic
Scope	Global	Class scoped

Business logic সবসময় Method এ

Function শুধু utility/helper এর জন্য

5. LOOP (CONTROL STRUCTURE)
foreach (Preferred)
foreach ($items as $item) {}


Collection iterate করার জন্য

Safe ও readable

for
for ($i = 0; $i < $n; $i++) {}


Index দরকার হলে

while
while ($condition) {}


Queue, stream, worker

Best Practices

Loop এর ভেতরে complex logic না

Loop → Method extract করুন

Nested loop দেখলে redesign ভাবুন

6. CONDITIONAL LOGIC
if / else

Simple condition

Decision branching কম হলে

match (Recommended)
$result = match($type) {
    Type::A => $this->handleA(),
    Type::B => $this->handleB(),
};


Strict comparison

Expression based

Exhaustive handling

7. ERROR HANDLING

PHP 8+ strict error দেয়

Warning ignore করা যাবে না

Fail fast principle

try {
    // risky operation
} catch (Throwable $e) {
    // handle properly
}

8. OOP PILLARS (SUMMARY)
